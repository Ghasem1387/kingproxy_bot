# KING PROXY Bot 👑

ربات تلگرام کینگ پروکسی: قفل کانال، کانفیگ/پروکسی خودکار، پست روزانه‌ی متنوع در کانال، استخراج بیت‌کوین با برداشت و پنل مدیریت.

## فایل‌ها
| فایل | کاربرد |
|---|---|
| `bot.py` | اجرای اصلی، منو، کیبورد پایین، صفحه‌ها |
| `admin.py` | پنل مدیریت (فقط ادمین) |
| `jobs.py` | بروزرسانی منابع + پست‌های روزانه‌ی کانال |
| `templates.py` | متن‌های متنوع پست‌ها (هر روز ترکیب متفاوت) |
| `feeds.py` | خواندن کانال‌های منبع، تست زنده بودن، برندسازی |
| `mining.py` | منطق استخراج (ضربه، باتری، دعوت، برداشت) |
| `miner.html` | صفحه‌ی استخراج (مینی‌اپ) — باید روی GitHub Pages باشد |
| `backup.py` | بکاپ/بازیابی دیتابیس داخل تلگرام |
| `db.py`, `ui.py`, `config.py` | دیتابیس، ظاهر، تنظیمات |

## استخراج بیت‌کوین
- باتری ۱۰۰ ضربه در روز • هر ضربه 0.0000001 BTC • هر دعوت فعال 0.000005 BTC • حداقل برداشت 0.00025 BTC
- صفحه‌ی استخراج (`miner.html`) با دکمه‌ی «⛏ استخراج» پایین چت باز می‌شود: تب‌های خانه، استخراج، کیف پول، دعوت، بیشتر.
- برداشت: کاربر از تب «کیف پول» آدرس BTC می‌فرستد (چک‌سام بررسی می‌شود) ← موجودی تا تصمیم ادمین نگه داشته می‌شود ← ادمین از پنل «💸 برداشت‌ها» تأیید/رد می‌کند (رد = برگشت موجودی). واریز بیت‌کوین را خودت انجام بده.

### راه‌اندازی صفحه (یک‌بار)
1. فایل `miner.html` را در ریشه‌ی مخزن بگذار.
2. Settings ← Pages ← Source: *Deploy from a branch* ← Branch: `main` / `(root)` ← Save.
3. بعد از ۱ تا ۲ دقیقه آدرس `https://<نام‌کاربری>.github.io/<نام‌مخزن>/miner.html` باید باز شود.
4. اگر آدرس فرق دارد، `MINER_URL` را در `config.py` عوض کن. در پنل ادمین دکمه‌ی «🧪 تست صفحه استخراج» وضعیت را نشان می‌دهد.
